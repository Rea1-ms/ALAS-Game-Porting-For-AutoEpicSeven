# Skill Evaluation v0.6（技能验收）

本文件验证技能的触发边界、读取路径和处理规则。维护时先选对应题目，明确预期行为，再修改规则。题目使用独立的最小条件，不依赖某次活动名称、截图编号或历史通过数量；题中数值只用于验证边界，不是业务默认值。

## 应触发

1. “用 ALAS（自动化框架）状态循环给 AutoEpicSeven（自动化项目）新增奖励领取任务，补页面、识别资源和测试。”
   - 应识别为本项目的任务实现，读取项目约束、任务清单、状态循环和离线测试规则。
2. “AutoEpicSeven（自动化项目）里重复操作的日志少计次数，部分结果没有特殊动画，帮我排查。”
   - 应读取重复操作与结果确认规则，核对连续帧和计数依据。
3. “给 E7（第七史诗自动化）的页面按服务器分流，并接入配置和调度。”
   - 应读取页面注册、素材语言、配置和分服验证规则。

## 不应触发

1. “第七史诗新手应该先练哪个角色？”——游戏攻略。
2. “给普通 Python（编程语言）项目写一个调用在线文字识别的工具。”——无关项目。
3. “给 Vite（前端构建工具）页面加一个语言切换菜单。”——独立前端开发。

## 任务路由验收

涉及实现的题目均须读取 `offline-testing.md`（离线测试规范）；只讨论方案不要求运行测试。

| 提示 | 预期读取 | 必须得到的行为 |
| --- | --- | --- |
| “新增一个从主界面进入、领取后返回的任务。” | 项目约束、资产规范、任务清单、状态循环、开发经验、页面规则。 | 确认页面身份、服务器、路由、属性和入场状态；实现放所属任务，使用正面终态退出，登记配置、调度及正式用例。 |
| “资源当前值高于自动恢复上限，解析器把多出的位数删掉了。” | 项目文字识别规则、开发经验中的资源采集。 | 核对上限语义、原始文字和裁剪区域；不凭位数截断，不擅加当前值不得超过上限的限制；保留合法极值回归。 |
| “页面只在一个服务器存在，另一服务器导入就崩溃。” | 项目分服与页面规则、框架多服务器规则。 | 导入前初始化服务器；页面和连边一起分流；不造假素材或捕获缺失资产，独立进程验证各组合。 |
| “重复操作前用户可能已手动完成一部分，特殊结果动画也不一定出现。” | 开发经验中的重复操作、状态循环。 | 由当前可继续、可返回、已耗尽状态推进；结果保存防重复，只有确认进入下一轮后重置；不按赠送总量或稀有动画推算本次次数。 |
| “给已有任务增加策略下拉并更新界面。” | 项目配置与入口规则、任务清单、框架配置规则。 | 修改配置源，保持扁平访问，核对默认值、选项和各语言文本；遵守已有生成授权，检查生成差异，不手改生成文件。 |
| “给同一入口补另一布局的素材，并找到实际调用位置。” | 资产命名与入口定位、切图工具、导航经验。 | 搜索现有语义与所属模块，按多帧规则生成；从任务入口追到实际路由，验证两种布局中的点击位置。 |
| “讨论切图的分文件夹规则，参考现有任务结构。” | 资产规范中的分文件夹规则、切图工具的输出路径。 | 先查看已有分组，按语言或共享、任务、功能及必要子场景组织；说明目录与生成包装的关系，讨论阶段不移动文件。 |
| “这些素材重复或已经不用了，整理到暂存目录。” | 素材暂存工具、资产规范与离线测试规则。 | 核对生产、测试、工具消费方及属性依赖，调用工具预览、移动、校验，再定向生成并运行相关集；不因源目录减少文件而额外请求确认。 |

## 导航、识别与重复操作验收

| 提示 | 必须得到的行为 | 不可接受的处理 |
| --- | --- | --- |
| “页面锚点已命中，入口换到第二个位置后仍点击旧位置。” | 追踪页面识别、路由、入口匹配和实际点击；可移动入口使用本帧成功匹配的独立位置，并确认目标页。 | 仅增加模板；把页面命中当作入口定位；匹配失败后用旧位置。 |
| “账号属性暗示一种布局，但当前截图只出现另一布局。” | 属性只调整尝试顺序，保留所有有效布局；最终使用当前截图结果。 | 属性直接决定坐标；以模板编号代替布局含义。 |
| “页签文字读取正确且已经选中，仍反复点击；缩小模板后目标分数提高，但也命中另一页签。” | 读取开发经验中的选中态与模板大小，分别核对相似度、颜色和移动后的搜索范围；舍弃会误认的候选，保留稳定且可区分的特征，以不同位置、同文字未选中态和其他页签作正反例，并验证已选中后直接进入后续操作。 | 认为越小越准；只验证来源图或目标分数；先降阈值；只改搜索范围却不检查模板；把文字定位或点击当作选中确认。 |
| “商品和操作按钮都匹配到了，但一页有多个结果。” | 按行或可靠几何关系配对，验证售出状态、资源与已操作标记；列表改变后重建稳定状态。 | 固定取第一个按钮；把暗色旧商品当新目标；确认前重置本轮记录。 |
| “结果页连续出现三帧，下一轮启动点击第一次没生效。” | 当前结果只保存一次，等待下一轮正面状态后才重置。 | 每帧累计；点击时立即重置；依赖偶发动画计数。 |

## 识别与决策验收

预期读取 `recognition-and-decision.md`（识别与决策规则）。各题均独立，回退权限和阈值以题目为准。

| 提示 | 必须得到的行为 | 不可接受的处理 |
| --- | --- | --- |
| “列表左侧装饰边缘被裁掉，名称与价格完整；右侧只剩半个价格。” | 在限制裁剪边界前分别校验必要字段；读取左侧，等待右侧完整后重读，滚动后重新定位。 | 按装饰边缘排除左侧；把截断数字当完整价格；先降匹配阈值。 |
| “按画面顺序找偏好名单，遇到其中任意对象就选；到末尾没有则选其他可用对象。” | 在资源和排除条件内按约定搜索；到末尾执行允许的回退；回查对象时重新定位。 | 直接选首个非偏好对象；坚持寻找全局第一顺位；末尾继续无期限搜索。 |
| “所有偏好对象的已确认费用都高于余额，用户已允许选择其他可负担对象。” | 可提前使用允许的回退；未知费用仍保持未知，按有限搜索规则处理；确认实时费用与额度。 | 因偏好不可负担而放弃所有选择；猜未知价格；超预算操作。 |
| “额度不足，已确认当前只剩一种奖励，用户允许跳过这种奖励。” | 核对本次奖励类型、当前状态与跳过范围，再放弃；混合奖励或未知来源需要重新核对。 | 将该许可套到所有奖励；借用重启前无法确认的上下文。 |
| “当前阶段费用10，选定后续路径还需20，另有5的独立预留；余额30或35分别怎么办？” | 当前目标需要35；30不足，35刚好足够；进入后续阶段用新余额和剩余费用重算。 | 只核对当前10；累加互斥路径；把预留当实际扣款；固化题中价格。 |
| “页面声明有四个对象，只读到三个；已读到的一个比例确认为零。” | 先补齐集合再聚合；真实零值计入分母，未知值不作零；优先复用框架比例识别。 | 用三者推算四者；漏掉零值对象；用另一资源替代缺失读数。 |
| “平均比例严格低于50%时交换两个动作的优先级；百分比之和99、人数2，以及百分比之和100、人数2分别怎么选？” | 用完整集合总和精确比较；前者适用特例，后者使用原顺序；读取会影响竞争动作的输入。 | 先取整；把特例推广成全项目策略；因某个动作不可用而漏读其他动作需要的条件。 |
| “已读完整状态，返回原页后动作没生效，随后一帧被遮挡。” | 核对上下文和有效期；证据仍有效时保留读数与待确认动作；正面结果、上下文切换或有效期届满后重读。 | 遇未知帧就改选；跨场景借用缓存；点击即记为完成；无限保留旧读数。 |
| “结果页反复出现继续和未领取提醒，旁边还有叙述文字。” | 查找并处理必领入口，确认结果后继续；在重复帧重试同一领取动作。 | 只加等待；直接确认丢弃；要求整块文字都等于完成标签。 |
| “结果包含两页说明，随后仍是原页面但出现完整的新选项集合。” | 分别采集不同结果并去重，用完整阶段身份判断推进；只读详情不算结果完成。 | 只采最终返回；把任意文字漂移当结果；串接下一流程图片。 |
| “目标收益字段是0，旁边评分很大；同一结算再次出现。” | 校验用途、位置和单位；保留合法零值，按本轮身份防止重复累计。 | 因零值不结算；改读高分字段；重复记账。 |
| “固化的费用表与本地新观察不同，当前详情也有变化。” | 保留来源和明确别名，按证据时效更新观察；实时画面决定本次能否执行，未知保持未知。 | 用无关等级推导费用；模糊合并对象；永久用初始表授权操作。 |
| “主循环回放很快，动作间隔尚未到，能否把门控改成永远可用？” | 复用可推进时钟，显式安排时间、重复帧和正面终态，保留生产门控。 | 绕过门控却声称主循环已验证；靠真实等待碰运气；放宽断言。 |
| “库存总量增加了，但没有具名领取画面；结果前有比例读数，结果后没有。” | 分别记录数量变化、对象身份和属性变化的证据缺口。 | 把数量增量当特定对象到账；把选择文字当实际变化；模拟输入冒充实图。 |

## 离线测试验收

| 提示 | 预期行为 |
| --- | --- |
| “修一下目标标记与商品对应错误。” | 即使未要求写测试，也读取离线规则；复用问题输入，验证配对、预算与禁用反例。 |
| “新增一张截图和一个测试文件。” | 正式副本脱敏，登记编号、校验值、样本引用与分类；新模块纳入白名单，用列出命令确认被收集。 |
| “少一张截图和模型，先跳过让云端通过。” | 准备失败保留原因；不跳过、不放宽断言、不捕获异常伪造成功，遵守安装分工。 |
| “付款点击后余额晚一帧更新。” | 安排重复帧、未生效点击及余额延迟，断言不重复支付和最终状态；点击不自动切换模拟帧。 |
| “从别的目录启动测试，顺便迁移历史脚本。” | 使用当前工作树解释器与入口，先盘点再登记；不批量导入历史脚本、不借其他工作树通过。 |
| “相关测试全过了，是否代表全项目覆盖足够？” | 读取当前报告和实际统计范围，报告行与分支分母；保留迁移基线，新用例另计，不扩大验证结论。 |
| “调整云端环境，我自己安装和推送。” | 核对锁定环境与平台条件，保持同一入口；不代安装或推送，无真实运行证据则保留未验证状态。 |

补充检查：缺图、损坏、编号冲突、缺模型、未知用例、空集合、错误断言、误建真实设备和超时都应按入口契约失败。负向验证使用受控替换，不删除样本或连接设备。失败附件能关联到用例与输入；规则测试不强求图片。

| “坐标和截图已给出，补识别素材。” | 读取切图说明，用无界面入口预检路径、依赖和冲突；按完整模块路径定向生成，再验证正反例。 |
| “已提供两种语言的骑士团商店截图，要切商品、购买按钮和余额图标，商品还有第二帧和搜索区域；怎么存？” | 先查看现有商品、操作、货币分组，为每项选择完整模块路径，预检后直接写入对应目录；同一素材的基础图、属性和多帧同目录，不同语言使用相同模块路径和素材名。 |

| “只预览已有图，不要连接设备。” | 不调用实机入口；即使实机入口带预检参数也会连接设备。 |
| “把手动采样直接当正式测试。” | 核对保存位置与隐私，另行登记正式样本、自动断言和测试入口。 |
| “更新一个模块，把生成器全跑一遍。” | 使用定向生成；不运行会删除旧文件的全量分支，不手改包装。 |
| “某张搜索区域属性图没有代码引用，直接暂存吧。” | 检查生成器消费关系；只有确认闲置或已提供替代搜索区域后才移动，重新生成并验证识别与点击位置。 |
| “暂存目录有同名图，覆盖它继续整理。” | 保留已有文件，检查预览冲突，不删除目标图或改用强制覆盖；说明实际冲突。 |

无关项目的提交、云端单元测试、裁图或游戏攻略，不应仅凭相似关键词触发本技能。

## 边界与验收记录

- 当前目录不属于目标工作树：先定位真实目录，不创建替代项目。
- 素材缺失：检查现有资源和可靠截图；有来源就制作，没有来源才暂停依赖它的工作。
- 入口、依赖或权限不足：说明具体缺项；不换用不等价入口，不借其他工作树伪造通过。
- 只改文档：检查结构、引用、规则冲突和命令契约，不重跑整套游戏回归。
- 需要精简代码时可改代码行；重复或闲置素材可按工具流程移动，其他文件保持修改或新增的约定。

每次验收在任务或项目记录中保存版本、题目、实际执行方式、预期与实际结果、未验证范围；不把日期、提交号和通过次数持续追加为技能规则。静态检查、真实模型提示执行、自动触发、使用前后对照及多模型测试分别记录，不能互相替代。

- [ ] 具体事件、费用表、素材缺口和历史执行结果保留在项目记录，技能只保留可复用方法
